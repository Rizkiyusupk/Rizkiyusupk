## Proyek dan Script

Repository ini berisi berbagai project infrastruktur dan automation yang saya bangun, meliputi:

- Provisioning multi-node Kubernetes cluster (KVM/QEMU, Terraform, Ansible)
- Push-based dan pull-based CI/CD pipeline (Jenkins, ArgoCD/GitOps)
- Hybrid cloud-native infrastructure (AWS service simulation via LocalStack)
- Observability stack end-to-end (Prometheus, Grafana, Loki, Alertmanager, alerting via Telegram)
- Otomasi manajemen user & konfigurasi server
- Setup dan deployment web server
- Monitoring log dan data
- Konfigurasi multi-platform (bare-metal, VM, container)

Tulisan lengkap dan penjelasan teknis tiap project dapat dibaca di blog: [rizkiyusupk.github.io](https://rizkiyusupk.github.io)
